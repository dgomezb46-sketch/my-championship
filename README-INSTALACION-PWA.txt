MY CHAMPIONSHIP 2.1 — INSTALACIÓN PWA

ARCHIVOS QUE DEBES SUBIR A LA RAÍZ DEL REPOSITORIO:
- index.html
- manifest.json
- service-worker.js

IMPORTANTE:
- Conserva los archivos icon-192.png e icon-512.png que ya existen en el repositorio.
- Antes de reemplazar el index.html, puedes descargarlo desde GitHub para guardar una copia.
- No elimines otros archivos del proyecto.

PUBLICAR CON GITHUB PAGES:
1. Abre el repositorio my-championship.
2. Entra en Settings > Pages.
3. En Build and deployment, elige Deploy from a branch.
4. Selecciona la rama main y la carpeta /(root).
5. Pulsa Save y espera a que GitHub publique el sitio.

INSTALAR EN ANDROID:
1. Abre la dirección de GitHub Pages en Chrome.
2. Espera a que cargue la aplicación.
3. Abre el menú de Chrome y elige Instalar aplicación o Añadir a pantalla de inicio.
4. Confirma la instalación.

DATOS:
Los datos se guardan en el almacenamiento local del navegador. Si ya tienes datos en otra versión, exporta un backup e impórtalo en la versión publicada antes de seguir trabajando.
